# 2026 蓝桥杯嵌入式备赛资料

这里整理了 2026 年蓝桥杯嵌入式方向的 STM32 HAL 学习工程、阶段练习和备赛笔记。工程基于 **STM32G431RB**，主要使用 **STM32CubeMX** 和 **Keil MDK-ARM**。

仓库保留了多个阶段版本，方便对照外设学习过程和功能迭代。大多数工程目录包含独立的 CubeMX 配置（`.ioc`）、Keil 工程（`.uvprojx`）、应用代码（`Core/`、`code/`）和 STM32 驱动（`Drivers/`）。

## 从哪里开始

- **`base_project/`**：基础工程，适合先熟悉工程结构和 HAL 初始化。
- **`3.3/`、`3.8/`**：早期外设练习版本。
- **`3.30_mode_one/`、`3.31_mode_two/`、`4.2_mode_three_usart/`**：数码管动态扫描及不同显示模式练习。
- **`4.4_th14/`、`4.6_th16/`、`4.10_th12/`**：阈值及显示练习的阶段版本。
- **`4.8_usart_dma/`、`4.8_mode_four_usart_dma_rtc_eeprom/`**：串口、DMA、RTC 和 EEPROM 等功能练习。
- **`4.11_test_base_project_time&&17moni1/`**：计时和综合练习版本。
- **`last/`**：当前最终整合工程，建议作为完整程序的阅读入口。

同一功能的代码可能在不同阶段版本间变化；请进入对应目录独立打开其 `.uvprojx` 工程。

## 打开和编译

1. 安装 Keil MDK-ARM 和 STM32G4 系列器件支持包。
2. 选择一个阶段目录，在它的 `MDK-ARM/` 下打开对应的 `.uvprojx` 工程文件。
3. 确认 Keil 使用的编译器版本、下载器和本机 STM32CubeMX/固件包配置。
4. 编译后再连接开发板下载。不同阶段的引脚、外设和功能可能不同，请先查看该工程的 `.ioc` 和 `Core/Inc/main.h`。

目录中的工程是个人备赛过程记录，不保证开箱即用。首次打开后如果本机工具链或固件包版本不同，可能需要在 Keil 或 CubeMX 中重新配置。
